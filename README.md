# 🏨 Hotel Management System (HMS)

A Windows Forms-based Hotel Management System developed in C# as part of a Systems Analysis and Design project.  
This system helps manage essential hotel operations such as bookings, check-ins, check-outs, room and guest management, employee access, and multilingual support.

---

## 📌 Features

### 🔐 User Authentication
- Login system with role-based access (Admin, Clerk)  
- First-time login prompts password change  

### 👥 Employee Management
- Add, update, and delete employee records  
- Auto-generate usernames and random passwords  

### 📆 Booking System
- Make new bookings  
- Search by guest name or contact number  
- Auto-fill guest and room details from booking  

### 📊 Report Generation
- Reports can be generated to provide meaningful insight  

### 🛎️ Check-In / Check-Out
- Verify booking before check-in  
- Update room availability  

### 🏠 Room Management
- Add, edit, delete room records  

### 🌐 Multilingual Support
- Toggle between English and Afrikaans  

### 🆘 Help System
- Tooltips and integrated user manual  

### ✅ Data Validation
- Strong input validation across all fields  

### 🎨 Visual Interface
- Clean, user-friendly layout with form-based navigation

## 🧪 How to Run

1. Clone the repository.  
2. Open the solution in Visual Studio.  
3. Attach or restore the SQL Server database.  
4. Run the project.

> 💡 **Note:** Default login credentials can be found in the `Users` table.  
> When creating a new user, they will be prompted to change their password on first login.
